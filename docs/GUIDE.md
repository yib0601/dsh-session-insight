# 每轮费用与用量总览

三条入口，一处配置。

| 入口 | 在哪 | 看什么 |
|---|---|---|
| 逐轮徽章 | 每条回复的动作行末尾 | 本轮金额；点开看模型、缓存命中与 token 桶明细 |
| 会话累计药丸 | 输入框下方状态栏 | 本会话累计；设了预算时是 `花费 / 预算` |
| 上下文 / 用量总览 | 会话「上下文」页签、右侧栏、`/context`；跨会话看侧栏脚 | 构成明细、命令与文件流水、按模型 / 按天花费、逐请求、订阅余量 |

## 金额怎么算

- 逐请求计价：按该请求**实际用的模型**与**发生时刻的高峰 / 空闲档**算，历史金额不随价目表变动。
- 官方人民币刊例价直接用；只有美元价的按汇率折算并标注。
- 未知模型显示「价格未知」，不按 $0 计。

## 配置在哪

都在设置里，插件页不放配置入口：

| 设置页 | 管什么 |
|---|---|
| 费用 | 徽章 / 状态栏显隐、币种、计费时段、会话预算 |
| 模型目录 | 网关路由的模型清单，跟随网关自动核对 |
| 记忆与笔记 | 项目记忆的索引偏好、笔记检索目录 / 开关 / 超时 |

完整界面说明见仓库里的 `docs/DETAIL.md`。
